HSE Accident Data Analysis

Project Overview

This project focuses on analyzing workplace accident data using Python and Pandas.

The objective is to identify accident patterns, high-risk areas, incident trends, and factors that can contribute to improving workplace health and safety performance.

Objectives

- Analyze workplace accident data.
- Identify the most common types of incidents.
- Analyze accident frequency and severity.
- Identify high-risk activities and work areas.
- Detect trends in workplace accidents.
- Provide data-driven recommendations for HSE improvement.

Tools

- Python
- Pandas
- Matplotlib
- CSV
- Data Analysis
- Data Visualization

Analysis

The project will analyze:

- Accident types
- Incident severity
- Work areas
- Contributing factors
- Accident trends
- Near Miss incidents
- Lost Time Injuries (LTI)
